# Hollow Delve cave backgrounds

Open [review.html](review.html) to compare three selected backgrounds, their
Pyxelate alternatives and the original SDXL renders. The page works offline.
`backgrounds.zip` contains the selected images, recipes, review and provenance.

These were generated by the repository's **local SDXL + Pixel Art XL pipeline
on Apple M3 Max**, using MPS and FP16. The selected renders took 133 seconds in
total, excluding model loading, setup and export. The first setup downloaded
6.78 GiB of pinned reference files.

| Scene | Export | SDXL source | Render time |
| --- | --- | --- | --- |
| Limestone cavern | [640×360 PNG](backgrounds/hollow_delve_landscape.png) | [1024×576 PNG](originals/hollow_delve_landscape.png) | 42.5 s |
| Excavated gallery | [640×360 PNG](backgrounds/hollow_delve_timber_gallery.png) | [1024×576 PNG](originals/hollow_delve_timber_gallery.png) | 46.2 s |
| Underground pool | [640×360 PNG](backgrounds/hollow_delve_sunken_cavern.png) | [1024×576 PNG](originals/hollow_delve_sunken_cavern.png) | 44.2 s |

Both export methods produce opaque 640×360 PNGs using only ENDESGA 32 colors.
The files are copied unchanged from pipeline exports. [proof.json](proof.json)
records seeds, timings, hashes, source runs, runtime settings and validation.
`provenance/` contains the original plans, environment records, indexes and
export manifests; each SDXL original has its generation JSON beside it.

## Reproduce

From the repository root, complete [Mac setup](../../PYTHON.md#apple-silicon-setup)
if needed. These backgrounds require only the environment and reference weights.
The commands also use the existing CUDA environment on Linux.

```bash
uv run sprites all --definition image-generation/scene-samples/hollow-delve-v1/backgrounds-v2.toml --run image-generation/sprite-pipeline/runs/hollow-delve-backgrounds-retry --seed 83000
uv run sprites all --definition image-generation/scene-samples/hollow-delve-v1/cavern-v3.toml --run image-generation/sprite-pipeline/runs/hollow-delve-cavern-retry --seed 83000
```

The gallery and pool are selected from `backgrounds-v2.toml`; the cavern uses
`cavern-v3.toml`, which removes figures from the earlier composition. The earlier
`definition.toml` and `passages.toml` preserve the initial art direction. Use a
new run directory for revisions. MPS results are not guaranteed byte-identical
between runs or to CUDA renders.

## Validation and visual review

Generation, pixel preparation, both export methods, review and native pipeline
packaging passed for the selected source runs. All nine selected PNGs were
verified readable; original and export hashes match pipeline records. All six
exports have the requested dimensions, opaque alpha and valid palette colors.
The three original and selected pixel compositions were visually inspected.
Local preview links and JavaScript syntax were checked.

The implementation passed 97 relevant tests. The first real MPS attempt exposed
a sliced-attention NaN failure; the fix keeps PyTorch's default attention and
rejects invalid pixels before PNG conversion. Pipeline code is recorded at
commit `3ac60f0`, following the Mac runtime setup in `734be9c`.

These are atmosphere candidates. The gallery reads as stone vaulting with
timber trim, and the pool fills the lower foreground with water. Ground
placement and collision need separate work, particularly a walking surface in
front of the pool. The backgrounds are opaque full scenes, without separate
parallax layers or verified horizontal tile seams. Wan animation and SAM2
inference were not tested by this static-background run.
